# WorkBuddy 连接器故障恢复

先确认工具来自 source 为 {{CONNECTOR_SOURCE}} 的当前连接器，目标为 {{MCP_URL}}。其他连接或终端的登录结果不能替代当前平台授权。

## 状态与动作

| 状态/错误 | 动作 |
| --- | --- |
| 无法安装、上传解析失败 | 记录连接器版本和平台具体错误，尚未进入 OAuth 或工具调用阶段 |
| 仍提示本地安装目录或启动器错误 | 确认已更新为远程版本；必要时从平台界面移除并重新添加本连接器，不手工修复系统目录 |
| 浏览器没有打开、取消或授权超时 | 从当前连接器授权入口重试，使用新授权流程，不循环弹窗 |
| OAuth 注册或回调失败 | 记录阶段、宿主/连接器版本和错误码，交由维护者核对实际回调及注册参数 |
| auth_required、明确授权失效或被撤销 | 在当前连接器重新授权，成功后调用账户工具再继续原任务 |
| token_refresh_failed、transport_error | 暂时无法刷新或连接，保留授权并重试；只有确认授权失效才重新登录 |
| permission_denied | 说明权限问题，核对账号与授权范围，不冒充未登录 |
| rate_limited | 按服务提示稍后重试，不重新登录 |
| invalid_params | 读取实时工具 schema 修正参数，不重新登录 |
| 记录为空 | 说明所查询来源暂无记录，不判断为授权失败或其他来源也无记录 |
| 有记录但总结不可读 | 只有明确缺少可读内容时才尝试其他候选，按返回 cursor 继续查询；说明实际检查范围 |
| 账号可读但额度调用失败 | 展示已取得的账号信息和额度失败阶段，不宣称整个任务完成 |

## 已授权但工具不可用

确认使用当前版本连接器及其评测授权，而非另一连接的登录状态。显示“无需授权”或 initialize 成功不能替代受保护工具调用；平台仍提示授权失效时重新授权，网络错误先重试。授权完成后工具尚未刷新，可重连当前连接器一次，不把工具已列出当成实际调用成功。

## 内容与笔记

patchxnote_get_memory 可能只提供元数据；可通过 patchxnote_render_webhook_message 的 Markdown 返回值取得可读笔记。不要传 save_draft=true、out 或本地路径。在聊天中展示返回内容，不能把标题/ID 当成完整笔记，也不因工具名包含 webhook 自动发送。

使用同一候选返回的 ID 和来源，不固定填 mobile。授权、权限或网络错误不是“没有总结”，应报告实际失败阶段。没有找到可读内容时说明检索范围，不编造正文或待办；该次笔记任务仍未完成。

## 质量评测未通过

先确认本次版本的真实授权与三条业务任务结果。若平台给出失败用例或调用日志，按对应阶段定位；只有“低质量”的总评时，不推断具体评分规则，也不把修改说明文案视为已修复运行故障。重新生成或提交后，验证结果应对应实际提交的同一候选包。

## 证据

只报告失败阶段、版本、时间、HTTP 状态或错误码，不输出令牌、授权码、完整回调查询参数或用户正文。当前环境为 {{ENVIRONMENT}}，API 为 {{API_BASE_URL}}；测试环境授权不能替代生产连接。
